# WHO ARE YOU? — Viral Character Battle

Experimental social-first web MVP built on `game-test`.

## Core loop

1. Create a ridiculous character in seconds.
2. Get stats, rarity and lore.
3. Challenge a friend with a shareable link.
4. Friend opens the link and sees the creation.

## Why this direction

The product is designed around a short time-to-value, user-generated outcomes and a natural sharing loop rather than a traditional game progression system. Current 2026 social trends favor fast, creator-led, participatory formats and authentic/shareable content.

## Stack

Zero dependencies: semantic HTML, CSS and vanilla JavaScript. It can be hosted as a static site on GitHub Pages, Vercel, Netlify or any static host.
